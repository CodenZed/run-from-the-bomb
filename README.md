# Run From The Bomb

A simple Windows Forms game built with C#.

## Gameplay
- Move the player left and right with the arrow keys.
- Avoid the falling bombs.
- Your score increases each time a bomb passes the player.
- When you collide with a bomb, the game ends and you can restart.

## Requirements
- Windows
- Visual Studio with .NET Framework 4.6.1 developer tools

## Run
1. Open `Run-From-The-Bomb.csproj` in Visual Studio.
2. Build the project.
3. Run the application.
